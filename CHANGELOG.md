# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## 1.1.0-beta1
- Fork maintained by Arquebus - contact/vendor info updated
- Expanded patch discovery: three-tier transpiler resolution (Harmony attributes, signature fallback, IL-parsing of manual Patch() methods)
- Harmony 2.4.2 support
- .NET 9+ support (backend targets net9.0)
- Async method visualization: transpilers targeting async methods now decompile the readable outer method instead of raw MoveNext IL
- Rider 2026.1 compatibility

## 2024.1.0
- Initial version (Zetrith/Remodder)
